Step 1 — Name the Switch
Module 2
▪ A clear hostname identifies the device in prompts, logs, LLDP and CLI
inventories
SWITCH#configure terminal
▪ Printable characters, max 63 bytes; takes effect immediately SWITCH(config)#hostname ANK-ACC-F2-01
ANK-ACC-F2-01(config)#
▪ Adopt a site convention, e.g. <SITE>-<ROLE>-<FLOOR>-<NN>
! Prompt changes instantly — instant confirmation
ANK-ACC-F2-01(config)#end
ANK-ACC-F2-01#write
Example convention Meaning
ANK-ACC-F2-01 Ankara HQ · access · floor 2 · unit 01
IST-ACC-DEPO-02 Istanbul depot · access · unit 02 Why it matters
During an outage you will be juggling several SSH sessions. The prompt is your only
guardrail against configuring the wrong box.

Step 2 — Management IP & Gateway
Module 2
▪ The management address lives on a VLAN interface — one per CLI
switch
! Static (recommended)
▪ Static addressing is best practice for infrastructure devices SWITCH(config)#management vlan 1 ip address 192.168.64.200/24
gateway 192.168.64.1
▪ DHCP option exists for staging/ZTP-style provisioning
! Or via DHCP (staging only)
▪ Gateway is required for management from other subnets SWITCH(config)#management vlan 1 ip address dhcp
! Verify
SWITCH#show management summary
Management interface with Ipv4:
Type: Static Vlan: 1
Ip address: 192.168.64.200/24
Gateway: 192.168.64.1
Design note — dedicated management VLAN
In production, move management off VLAN 1 to a dedicated VLAN (e.g.
VLAN 10) once VLANs are built in Module 3: management vlan 10 ip address
…
Careful over remote sessions
Changing the management VLAN/IP over SSH cuts your own session. Do IP changes from console, or plan your re-connection first.

Step 3 — Change the Default Password
Module 2
▪ Factory default admin / admin is public knowledge — change it CLI
before the switch touches the network
! Change built-in admin password
▪ Same command adds a user or changes an existing user's password SWITCH(config)#username admin password Gc7!x2#vQ9pL
! Add a named break-glass account
▪ 0–32 characters · case-sensitive · stored encrypted
SWITCH(config)#username anw-ops password N3t!Adm1n$26
▪ Create a second (break-glass) admin account and store its password ! Remove a user (must be offline)
SWITCH(config)#no username olduser
in your password manager
! See who is logged in
SWITCH#show users
Type Line User Idle Host
con 0 admin 00:00:03 --
Password policy (minimum)
12+ characters · upper/lower/digit/symbol · unique per site · rotated on staff change · never the model name, company name or 'angora123'. An online user cannot be
deleted — clear the line first (clear line vty N).

Step 4 — Harden the Management Plane Module 2
Service Default Enable Disable Verdict
SSH disabled ssh-server enable no ssh-server enable ENABLE — encrypted CLI
Telnet disabled telnet-server enable no telnet-server enable KEEP OFF — cleartext
Web HTTP/HTTPS disabled web-server enable {all|http|https} no web-server enable KEEP OFF in CLI-managed sites
CLI ▪ All three services are disabled at factory default — enable only
what you need
! Enable only SSH for remote management
SWITCH(config)#ssh-server enable ▪ Telnet and HTTP send credentials in cleartext — never on
SWITCH(config)#no telnet-server enable
production networks
SWITCH(config)#no web-server enable
! Restrict SSH to the NOC subnet via ACL ▪ ACL access-class limits who may even attempt to log in
SWITCH(config)#ip-access-list standard 10
▪ transport input none on unused vty lines caps concurrent sessions
SWITCH(config-std-acl)#permit 192.168.64.0/24
SWITCH(config-std-acl)#exit
SWITCH(config)#ip ssh access-class 10
! vty lines: allow SSH only
SWITCH(config)#line vty 0 7
If the customer insists on a GUI
SWITCH(config-line)#transport input ssh
Enable HTTPS only: web-server enable https — never plain HTTP.

Step 5 — Time: NTP & Timezone
Module 2
▪ Correct time = trustworthy logs, certificates and troubleshooting CLI
timelines
! Point at the site (or public) NTP server
▪ NTP server is set by IP address (domain names not supported) SWITCH(config)#ntp server 192.168.64.10
SWITCH(config)#clock timezone Istanbul
▪ First synchronisation takes about 4–8 minutes
! Manual fallback if no NTP available
▪ Default timezone is UTC — set your local zone (e.g. Istanbul, UTC+3) SWITCH#clock set 15:30:00 20 july 2026
! Verify
▪ clock set exists for offline/manual time if no NTP is reachable
SWITCH#show ntp status
SWITCH#show clock
Field practice
Use the customer's internal NTP source where one exists (domain controller, router). Only fall back to public NTP if the management network has outbound reachability
— many secure LANs do not.
