

Introduction

It adopts a storage and forwarding mechanism, and internally integrates a high capacity cache to ensure that all ports can achieve 10G non-blocking line speed forwarding for more emergency situations
With a durable and high strength fan steel shell design, the efficient heat dissipation ensures stable operation

This switch has 8*10 Gigabit RJ45 ports enjoying
seamless connection for 10/100/1000/2500M/5G/10G Ethernet
easy to manage and maintain
without extra configuration
support cloud management

It is ideal for high-speed connectivity between WiFi 7 access points, storage servers, and other devices

Key Features

Supports 8 *10 Gigabit RJ45 ports
Supports IEEE802.3, IEEE802.3u, IEEE802.3x, IEEE802.3ab, IEEE802.3z
RJ45 port supports 1.25G/2.5G/10G adaptive
Supports automatic port flipping (Auto MDI/MDIX)
Adopting a storage and forwarding exchange mechanism
All ports support line speed switching
The panel indicator lights will monitor the working status and assist in fault analysis
Support QoS data priority
Support web management
