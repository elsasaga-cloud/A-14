目的： 评估主力吸筹效率。 核心逻辑： AEI = 筹码收集效果 / 资金消耗代价。 
AEI值越高： 表示主力吸筹越隐蔽、效率越高（例如：在缩量或温和放量背景下，实现了筹码集中度提升或获利盘激增）。

规则如下

输入（每日数据）：
conc_t：集中度（%，e.g., 13.30）
profit_t：获利比例（%，e.g., 13.97，核心变量）
vol_t：成交量（万股，e.g., 38.43）
M：历史滚动窗口期（默认20日）
ε：防零常数（固定为1e-6）

1. 计算步骤（每日执行） 计算历史均值（过去M日，排除当日）：
meanV = 前M日成交量平均值

2. 计算日间变化：
ΔC = conc_t - conc_{t-1}（集中度变化）
ΔP = profit_t - profit_{t-1}（获利比例变化）

3. 计算“有效吸筹力度”（Numerator: Power）与信号过滤：
过滤微小噪音：
if ΔC < 0.05: ΔC = 0
if ΔP < 0.5: ΔP = 0 （获利盘波动通常较大，阈值设为0.5以过滤自然波动）
双引擎核心逻辑（取最大有效值）：
Power = max(ΔC, ΔP * 0.4)
注：系数 0.4 是为了将获利盘变化的量级平滑至与集中度相当的水平，防止数值失真。

4.计算标准化 AEI（核心公式）：
if Power <= 0:
    AEI_t = 0.0  # 无效（无筹码集中 且 无获利盘增加）
else:
    # 分母衡量“资金消耗/努力程度” (Effort)
    # 使用 (vol_t / meanV) 代表当日成交量相对于历史均量的倍数。
    # 逻辑：成交量越低（Effort越小）但Power很大，则AEI越高（效率极高，隐性吸筹）。
    Effort = (vol_t / meanV) + ε
AEI_t = Power / Effort

5.平滑处理（可选，减少噪音）：
AEI_smoothed = EMA(AEI_t, span=3)

## V3 优化 1：Easy Mode 的“深水空头”阈值做成波动自适应（不再固定5%）

- 设：`TH = max(0.05, 2 * ATRp)`  （2可以调参：1.5~2.5）

## V3 优化 2：斜率/GS 用“回归斜率”替代“隔日差”，并做标准化
### 你当前问题
`Slope = MA_today - MA_yesterday` 太短周期，噪音大；而且不同价格区间不可比。

### 最小改动方案（强烈推荐）
对每条均线 MAx，用最近 **k=5** 日做线性回归斜率，并标准化成“%/日”：

- `slope_x = LinearRegressionSlope(MAx[-5:]) / P`  
- 输出更稳定，GS会更可信。

**GS模型**也建议从“数值大小”改成更鲁棒的评分：
- 上拐（slope>0）根数占比
- + 长期线权重更高（MA60~MA90）

例如：
- `GS = 5 * (0.3*UpShort + 0.4*UpMid + 0.3*UpLong)`  
其中 UpShort=MA5/10 上拐占比，UpMid=20~50，上拐占比，UpLong=60~90。

## V3 优化 4：AEI 加两条“方向校验”，否则容易把派发当吸筹
### 你当前 AEI 的核心风险
- 你把 Power 定义成 `max(ΔC, ΔP*0.4)`，但 **ΔC 下降（筹码更分散）并不会扣分**。
- 获利比例 ΔP 可能因为短线拉升/回落而大幅波动，导致 AEI 脉冲式放大。

### 最小改动（不推翻原模型）
**(1) 加“发散惩罚项”**  
当 ΔC < -0.05（集中度显著下降）时，直接把 Power 置为 0 或负值：

```python
if ΔC <= -0.05:
    AEI_t = -abs(ΔC)  # 直接标记为派发/发散
    continue
```

**(2) 加“价格确认门槛”**（非常关键）  
吸筹的获利比例上升，必须伴随 **价格不弱**，否则可能是短线脉冲：
- 若 `P < MA20` 且 ΔP 很大：把 ΔP 权重减半或直接过滤。

```python
if P < MA20:
    ΔP_effect = ΔP * 0.2  # 原来是 0.4，这里降权
else:
    ΔP_effect = ΔP * 0.4
Power = max(ΔC, ΔP_effect)
```

这样 AEI 的“主力吸筹”解释会更贴近盘面常识：**筹码更集中 + 价格结构不破** 才算真吸筹。

> 另外：你要求“最近20交易日AEI”，实操时一定要保证数据连续；不连续就必须降级为“可用窗口 n<20 的临时结论”，否则误差很大。

目的： 评估主力吸筹效率。 核心逻辑： AEI = 筹码收集效果 / 资金消耗代价。 
AEI值越高： 表示主力吸筹越隐蔽、效率越高（例如：在缩量或温和放量背景下，实现了筹码集中度提升或获利盘激增）。

规则如下

输入（每日数据）：
conc_t：集中度（%，e.g., 13.30）
profit_t：获利比例（%，e.g., 13.97，核心变量）
vol_t：成交量（万股，e.g., 38.43）
M：历史滚动窗口期（默认20日）
ε：防零常数（固定为1e-6）

1. 计算步骤（每日执行） 计算历史均值（过去M日，排除当日）：
meanV = 前M日成交量平均值

2. 计算日间变化：
ΔC = conc_t - conc_{t-1}（集中度变化）
ΔP = profit_t - profit_{t-1}（获利比例变化）

3. 计算“有效吸筹力度”（Numerator: Power）与信号过滤：
过滤微小噪音：
if ΔC < 0.05: ΔC = 0
if ΔP < 0.5: ΔP = 0 （获利盘波动通常较大，阈值设为0.5以过滤自然波动）
双引擎核心逻辑（取最大有效值）：
Power = max(ΔC, ΔP * 0.4)
注：系数 0.4 是为了将获利盘变化的量级平滑至与集中度相当的水平，防止数值失真。

4.计算标准化 AEI（核心公式）：
if Power <= 0:
    AEI_t = 0.0  # 无效（无筹码集中 且 无获利盘增加）
else:
    # 分母衡量“资金消耗/努力程度” (Effort)
    # 使用 (vol_t / meanV) 代表当日成交量相对于历史均量的倍数。
    # 逻辑：成交量越低（Effort越小）但Power很大，则AEI越高（效率极高，隐性吸筹）。
    Effort = (vol_t / meanV) + ε
AEI_t = Power / Effort

5.平滑处理（可选，减少噪音）：
AEI_smoothed = EMA(AEI_t, span=3)

## V3 优化 1：Easy Mode 的“深水空头”阈值做成波动自适应（不再固定5%）
### 你当前问题
固定 5% 在 A 股里对：
- 低波动票（银行、消费）：5%可能已经是明显破位；
- 高波动票（小盘、题材）：5%可能只是正常摆动。

### 最小改动方案（推荐）
把 5% 改成 **max(5%, k×ATR%)** 的动态门槛：

- 计算：`ATRp = ATR(14) / P`
- 设：`TH = max(0.05, 2 * ATRp)`  （2可以调参：1.5~2.5）
- 判定改为：  
  `if Gap60>TH and Gap90>TH => TRASH`

这样你的“一眼定生死”在不同股性上会更一致。

> 你原来的“斜率为负一律加刑”保留，但斜率建议用V3方案（见下一条）。

## V3 优化 2：斜率/GS 用“回归斜率”替代“隔日差”，并做标准化
### 你当前问题
`Slope = MA_today - MA_yesterday` 太短周期，噪音大；而且不同价格区间不可比。

### 最小改动方案（强烈推荐）
对每条均线 MAx，用最近 **k=5** 日做线性回归斜率，并标准化成“%/日”：

- `slope_x = LinearRegressionSlope(MAx[-5:]) / P`  
- 输出更稳定，GS会更可信。

**GS模型**也建议从“数值大小”改成更鲁棒的评分：
- 上拐（slope>0）根数占比
- + 长期线权重更高（MA60~MA90）

例如：
- `GS = 5 * (0.3*UpShort + 0.4*UpMid + 0.3*UpLong)`  
其中 UpShort=MA5/10 上拐占比，UpMid=20~50，上拐占比，UpLong=60~90。

## V3 优化 3：现价差值法把 D 改成“百分差”，并让“粘合阈值0.3%”动态化
### 你当前问题
D 用绝对价差会受股价水平影响；粘合阈值 0.3% 仍是固定常数。

### 最小改动方案
用百分差：
- `d5 = (P-MA5)/MA5`，其余同理
