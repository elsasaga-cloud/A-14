# 二、为什么“有时候可以，有时候不行”

你这个场景 99% 是这几个原因👇

## 1️⃣ 东方财富页面是“动态加载”的（核心原因）

你用的是：

```python
time.sleep(8)
```

👉 问题：
- 页面不是8秒就一定加载完成
- 筹码分布是“延迟渲染”的模块（点击后才加载）

所以会出现：

| 情况 | 结果 |
|------|------|
| 网速好 | 能抓到 |
| 网速慢 / JS慢 | 抓不到 |

---

## 2️⃣ XPath 写死（非常致命）

你用的是这种：

```python
/html/body/div[1]/div/div[5]/div[1]/div/div[3]/div/div[4]/div/table/tbody
```

👉 这是**绝对路径**

问题：
- 页面只要改一点结构 → 直接失效
- 弹窗 / 广告 / DOM变化 → XPath变掉

---

## 3️⃣ 页面可能没切到“筹码分布”

你前面是有点击：

```python
li[4]
a[1]
```

👉 但现实是：

- 有时候点击失败
- 有时候按钮没加载出来
- 有时候被遮罩挡住

➡️ 结果：
**根本没进入筹码分布 tab**

---

## 4️⃣ 反爬 / 限速（非常关键）

东方财富其实是有风控的：

你现在是：

```python
for stockID in hstockIDList:
    getStock(1,stockID)
```

👉 等于：

- 一口气打开多个浏览器
- 高频访问

结果：

- 页面加载变慢
- JS资源加载失败
- 某些模块直接不给你（比如筹码）

---

# 三、为什么“后面才开始出问题”

你说：

> 一开始OK，后面不行

👉 典型特征：

### ✔️ 前期
- 没被风控
- JS正常加载

### ❌ 后期
- 被限速 / 风控
- 页面加载不完整
- 某些DOM直接没了

## ✅ 1. 别用 time.sleep → 用显式等待

```python
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

def wait_for_element(xpath, timeout=15):
    try:
        return WebDriverWait(driver, timeout).until(
            EC.presence_of_element_located((By.XPATH, xpath))
        )
    except:
        print(f"等待失败: {xpath}")
        return None
```

def get_kline_and_ma(jiaoyisuo, stockID):
