GPT 的 token 收费标准本质上是：**按输入 token + 输出 token 分开计费，不同模型价格不同**。

我给你用“人话版 + 常见结构”讲清楚：

---

## 一、什么是 token
- 1 token ≈ 0.75 个英文单词（粗略）
- 中文一般：**1 个汉字 ≈ 1~2 tokens**
- 例如一句“你好世界”大概 4~6 tokens

---

## 二、收费公式
> 总费用 = 输入 tokens 费用 + 输出 tokens 费用

通常：
- 输入（prompt）便宜一点
- 输出（completion）贵一点

---

## 三、典型 OpenAI API 价格（2026常见结构，美元/1M tokens）

### 🔹 GPT-4o（主力模型）
- 输入：约 **$5 / 1M tokens**
- 输出：约 **$15 / 1M tokens**

---

### 🔹 GPT-4o mini（便宜版）
- 输入：约 **$0.15 / 1M tokens**
- 输出：约 **$0.60 / 1M tokens**

---

### 🔹 GPT-5 系列（如果你在 ChatGPT 产品内）
一般是“分层计费/订阅+调用混合”，API端通常会：
- 更高能力模型 → **输入/输出都明显更贵**
- 但具体价格会按版本（mini / standard / pro）分级

---

## 四、一个直观例子

假设你问一句话：

- 输入：1,000 tokens
- 输出：2,000 tokens

用 GPT-4o：

- 输入成本：1000 × $5 / 1,000,000 = $0.005
- 输出成本：2000 × $15 / 1,000,000 = $0.03  
👉 总共约：**$0.035（3.5美分）**

---

## 五、关键规律（很重要）
1. **输出比输入贵 2~3 倍**
2. **长对话 = 成本快速累积（因为历史上下文也算 token）**
3. **系统提示词（system prompt）也计费**
4. 图片/工具调用另算（如果是多模态）

---

## 六、如果你关心的是 ChatGPT（非 API）
- ChatGPT Plus/Pro 是 **订阅制，不按 token 单独收费**
- 但后台依然有 token 限制（只是你看不到）

---

这个会比官方表更有实际意义。
