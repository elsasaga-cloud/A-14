# 一、它到底是干啥的（人话版）

你可以把它理解为：

👉 **“通信界的瑞士军刀 + 老电信网核心设备”**

它同时干这几件事：

### 1️⃣ 传输（核心功能）
- SDH光传输（运营商老骨干网）
- PDH / E1 / STM-1 / STM-4 / STM-16
- 本质：**把各种信号在不同节点之间搬运**

👉 类似：
- 你做的交换机：搬以太网包  
- 它：搬“各种协议 + 各种时代的通信信号”

---

### 2️⃣ 交换（不是以太网那种）
它支持：
- DXC（数字交叉连接）
- VC12 / VC4 cross connect

👉 本质：
- 类似“时隙级别交换”
- 不是MAC/路由，而是**电信级电路交换**

---

### 3️⃣ IP融合（关键点）
它还能干：

- Ethernet（GE / FE）
- TDM over IP
- SIP / IPPBX

👉 这就很关键：
👉 它在做 **“传统通信 → IP网络过渡桥梁”**

---

### 4️⃣ 语音系统（很强）
直接内置：

- IPPBX（电话交换机）
- SIP注册（400电话）
- FXO / FXS / E&M

👉 说白了：
👉 **直接能当企业电话系统用**
