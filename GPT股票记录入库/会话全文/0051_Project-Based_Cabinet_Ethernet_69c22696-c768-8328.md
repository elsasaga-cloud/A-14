A Project-Based Cabinet Ethernet Solution

Overview

The Project-Based Cabinet Ethernet Solution is a flexible, modular networking platform designed to meet diverse project requirements in industrial, security, and enterprise environments. 
Rather than offering a fixed-function device, this solution provides a customizable enclosure-based architecture, allowing multiple subsystems to be integrated into a single compact cabinet.

At its core, the product is not just a switch or router—it is a scalable hardware platform that combines power, networking, and control modules based on specific project needs.

---

## Flexible Cabinet Design

The cabinet serves as the foundation of the solution. It is engineered to accommodate different internal configurations, including:

* Power supply modules (AC input / DC conversion)
* Cooling systems (fan or fanless design)
* Main control boards (switching, routing, or hybrid)
* Fiber and Ethernet interfaces

As shown in the internal structure:

* The upper section integrates the AC power input and power conversion board, responsible for stable power delivery and PoE support.
* The lower section is reserved for the main control PCB, which can host switching chips, routing modules, or customized application logic.
* Side-mounted fans and ventilation paths ensure proper airflow and thermal stability.

This layered design allows efficient separation of power, control, and thermal zones, improving reliability and maintainability.

---

## Modular Functional Integration

This solution supports multiple functional modules within the same enclosure:

### 1. PoE Switching Module

* Provides power and data to IP cameras, access points, and industrial devices
* Supports IEEE 802.3af/at (and optional bt)
* Ideal for surveillance and IoT deployments

### 2. Embedded Router Module

* Handles Layer 3 processing:

  * NAT
  * VPN
  * Firewall
  * Routing
* Connected internally via Ethernet to the switch core
* Enables unified edge gateway functionality

### 3. Fiber Uplink & Bypass Module

* Supports SFP/SFP+ uplinks (1G/10G)
* Optional fiber bypass (fail-open) ensures network continuity during power failure
* Suitable for telecom and security-sensitive applications

### 4. Power System (AC Input + Conversion)

* Integrated AC input with internal DC conversion
* Supplies:

  * PoE power
  * Mainboard logic power
* Designed for high efficiency and stability under load

### 5. Thermal Management System

* Fan-assisted or fanless (aluminum enclosure) options
* Directed airflow design:

  ```
  Air In → Power → Mainboard → Vent Out
  ```
* Ensures stable operation even under high PoE load conditions

---

## Key Advantages

### 1. High Customization Capability

Each project can define its own configuration:

* Port count and type
* Power budget
* Router capability
* Cooling method

### 2. All-in-One Integration

Combines multiple devices into a single unit:

```
PoE Switch + Router + Power Supply + Fiber System
```

Reducing:

* Deployment complexity
* Cable interconnection
* Failure points

---

### 3. Industrial Reliability

* Isolated power and signal design
* Optimized heat dissipation
* Support for continuous operation in demanding environments

---

### 4. Scalable Platform Approach

The same cabinet can be reused across different projects by simply changing:

* PCB design
* Internal modules
* Firmware/software

This makes it ideal for:

* OEM/ODM projects
* Customized network appliances
* Vertical industry solutions

---

## Typical Application Scenarios

### • Smart Surveillance Systems

```
IP Cameras → PoE → Switch → Router → Fiber Uplink → Control Center
```

### • Industrial Automation

```
PLC / Sensors → Switch → Embedded Router → VPN → Remote Monitoring
```

### • Telecom Edge Nodes

```
Access Devices → Fiber Bypass → Secure Gateway → Core Network
```

### • Enterprise Branch Networks

```
Office Devices → PoE Switch → Router → ISP / Cloud
```

---

## Conclusion

The Project-Based Cabinet Ethernet Solution transforms traditional networking devices into a flexible, integrated platform. By combining power systems, switching, routing, and thermal management within a single customizable enclosure, it enables efficient deployment of tailored network solutions across various industries.

In essence, this is not just a product—it is a hardware ecosystem designed for project-driven innovation.

Smart Delay Start Protection
电源恢复后，网络设备仍在启动？

延迟期间：链路保持旁路状态
延迟结束：自动恢复正常模式
彻底杜绝电源恢复瞬间的链路闪断
真正做到零感知、零抖动

1 应用的原理
正常上电时	
A -设备（bypass）-B，保护模式
掉电时
A -bypass-B，直通模式
 
2 为啥要加这个延时切换的功能
在具体使用中，bypass只针对光层，和流量没关系
但是，A和B可能会覆盖不同的设备
可能是低速光模块比如1G，也可能是核心交换机100G光模块

掉电后，直通
此时，需要维修或恢复供电
在供电后
A和B设备的启动时间差异可能会很大
比如一个核心交换机的重启，加载，链路跑通可能需要几分钟的时间

如果没有这个延时切换功能
那就是直接切换到bypass保护模式
此时就是
A -设备（bypass）-B，保护模式
但因为A和B设备并没有完全加载完毕，数据互通其实是不正常的
就会出现流量丢包或者监控异常报警的情况

有了这个延时切换功能（delay timer)
相当于给了A B设备一定的时间来完全加载完毕
再切换链路至bypass保护模式
此时
上电正常
A B通信正常
Bypass保护正常

这种应用用于下述情况
1 电源不稳定/波动
这可以防止光链路来回切换（直通，bypass保护，直通，bypass保护）
等电源彻底稳定，再恢复bypass保护模式，设备正常通信

2 上述提到的设备未完全加载的情况
可能出现在机房（大型交换机），远端维护，设备故障后重启，掉电后立马来电
等等场景
其实2中的场景都是，设备完全加载需要时间，不能立马切回正常通信（bypass保护模式），否则会数据丢包，通信报警等

它的核心用途就是，上电后给A B设备缓冲时间用于完全加载
然后再切换回正常的数据通信（bypass保护模式）

3 如何实现的这个功能
相比常规的光开关，这种光开关多了一个延时切换的功能（delay timer）
