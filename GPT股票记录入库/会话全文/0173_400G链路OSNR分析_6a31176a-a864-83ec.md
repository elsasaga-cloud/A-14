1. 为什么要 DCM？
非相干传输（10G/25G/100G彩光模块）对色散极度敏感，超过容忍范围信号就跑不稳。
DCM 就是“光学纠错器”，把多出来的色散补回来。
话术：您这条链路超过模块自带的容忍度，就得补 DCM，否则会掉包、误码，传不稳。

2. DCM 插入损耗
DCM 自身损耗很大（4~6 dB），补色散的同时把光功率吃掉。
因此几乎必然要配 EDFA/BA/PA 光放大器。
话术：DCM是必需的，但它会让光功率下降，所以我们会配套放大器，保证链路 OSNR。

3. 价格和成本痛点
DCM 本身价格高（尤其是长距补偿），而且还要配放大器，整体成本更高。
话术：这是传统方案的缺点，所以现在客户升级相干方案就是为了省掉 DCM 和额外放大器，整体 CAPEX/OPEX 更低。

4. 常见客户疑问

问：能不能便宜点？
答：DCM 本身就贵，加上放大器总价高，如果您要节省预算，建议考虑相干。

销售必知要点
1. BA / PA 是什么？
BA (Booster Amplifier)：发端侧用的放大器，把光模块的输出功率放大，提高入纤功率。
PA (Pre Amplifier)：收端侧用的放大器，把经过链路衰减的弱光放大到接收模块能识别的范围。
简单记：BA推上去，PA拉上来。

2. 为什么需要？
链路损耗大，光模块本身的发射功率不够，收端就会收不到或者 OSNR 太低。
所以点对点链路经常要搭配 BA + PA 组合。

3. 常见计算：
入纤光功率 = 光模块 Tx 功率 – 链路损耗 + 放大器增益
要保证 ≈ 0 dBm 左右（不能太低，否则收不到；不能太高，否则接收端过载）。
案例：
模块发射 4 dBm，链路损耗 25 dB → 到收端前只剩 -21 dBm。
如果加一个 PA，增益 21 dB → -21 + 21 = 0 dBm → 刚好合适。
话术：放大器的目标就是让收端看到的光功率在合适的区间，不会太弱也不会过载。

4. 客户常问 1：什么时候要加放大器？
答：链路长、损耗大时必须加，不然跑不稳。

客户常问 2：加 BA 还是 PA？
答：长距离通常两端都加；如果只是保证收端有信号，至少要加 PA。

客户常问 3：带 V 和不带 V 区别大吗？
答：带 V 可调范围更大，适合链路条件多变或未来可能调整的场景

BA 是推的，PA 是拉的；目标就是保证收端光功率在 0 dBm 左右。
链路越长，放大器增益就要越大。常用 16G25 / 16G30，带 V 的可调节范围更大，更灵活。

1. 放大器的关键参数（销售必备）
饱和输出功率（Psat）：比如 16 dBm、20 dBm，代表放大器能“推”的最强功率。
实用：链路长、通道多，就要更高的饱和输出功率（否则输出被压缩，OSNR 下降）。

增益（Gain）：比如 25 dB，就是能把光信号放大多少。
 实用：看链路损耗选，常见 12、15、25、30 dB。

噪声系数（NF，Noise Figure）：一般 5~6 dB。
实用：NF 越低越好，说明放大器“放大信号的同时带来的噪声更少”，OSNR 更高。
（你可以记住一句话给客户讲：增益大 → 信号强，NF低 → 信号干净。）

2. BA 和 PA 的作用定位
BA（Booster Amplifier）：放在发端，提升发射功率 → 解决“推不远”问题。
PA（Pre Amplifier）：放在收端，提升接收灵敏度 → 解决“收不到”问题。
很多工程里是 BA+PA 一起用，保证两端都稳。

3. 可调增益（带 V不带 V）
不带 V：±3 dB 调节范围（例如 25 dB → 22~28）。
带 V：±5 dB 调节范围（例如 25 dB → 20~30）。
带 V 更灵活，适合链路不确定、需要调优的场景。

4. 与链路的关系
链路损耗越大 → 需要更大增益。
波长通道越多 → 需要更高饱和输出功率。（因为功率要在多个通道之间分摊）

放大器自身噪声 → 限制了可传输的最大距离。
实用话术：“光放大器不是万能的，只能延长一定距离，距离再长就要多级放大，或者改相干方案。”

5. 销售常见问答话术
Q：为什么不能只用一个 BA？
A：如果链路很长，没有 PA，收端可能收不到信号；BA 只能负责“推出去”，PA 才能“拉回来”。

Q：16G25 和 16G30 差在哪？
A：30 dB 增益更大，能补偿更长距离损耗，但成本更高，一般长距才用。

Q：带 V 的是不是更好？
A：带 V 灵活，但也更贵。如果链路参数明确、固定，可以用不带 V；如果不确定，建议用带 V。

BA/PA 的核心就是三点：功率够不够远（饱和输出功率）、能补多少损耗（增益）、信号干不干净（噪声系数）。长距点对点常用 BA+PA 组合，型号像 16G25、16G30，带 V 的更灵活，适合链路复杂的场景。

1. 增益（Gain） vs 饱和输出功率（Psat）
它们是两个不同的参数：
增益（Gain）：
→ 代表放大器能把输入信号“放大多少倍”。
比如 25 dB 增益，意思是：输入信号 -20 dBm → 输出就 +5 dBm。
增益只看“输入和输出之间的差值”

饱和输出功率（Psat）：
→ 代表放大器能“推”的最大极限输出。
比如 16 dBm，意思是：再怎么放大，输出也不会超过 16 dBm。
超过这个点，信号会压缩、失真，OSNR 下降。

区别总结：
增益 = “能放大多少”
Psat = “最多能推多少”

2. 为什么“通道数多 → 需要更高 Psat”？
因为放大器输出的总功率要分给所有波长（通道）：
假设 Psat = 16 dBm（大约 40 mW 总功率）
如果只有 1 个通道：这 16 dBm 全部给它 → 每通道 16 dBm
如果有 16 个通道：每个通道就只能分到大约 4 dBm（均分假设）
所以：通道越多，单通道分到的功率越小，这时候就需要更高的 Psat 来保证每个通道的信号强度够。

3. 噪声系数（NF，Noise Figure）
NF 是放大器在“放大信号”的同时“引入多少额外噪声”的指标。
一般 EDFA 在 5~6 dB → 你培训资料里写的 6 dB 就是典型值。
这个参数确实比较固定，不同厂家型号差不多，不会差太大。
你可以记一句话给客户说：
我们放大器的 NF 在行业标准 5~6 dB 之间，属于低噪声等级，对长距离传输的 OSNR 影响很小。

类比（简单版）
增益 = 水龙头的“放大倍数” → 你开多大水流。
Psat = 水管的“最大流量” → 不管你怎么开，管子最多只能出这么多水。
NF = 水里混进的杂质 → 水是放大了，但也带来了一点点浑浊。
