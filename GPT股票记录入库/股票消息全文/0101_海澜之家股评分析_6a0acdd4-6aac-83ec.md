AEI值越高： 表示主力吸筹越隐蔽、效率越高（例如：在缩量或温和放量背景下，实现了筹码集中度提升或获利盘激增）。

规则如下

输入（每日数据）：
conc_t：集中度（%，e.g., 13.30）
profit_t：获利比例（%，e.g., 13.97，核心变量）
vol_t：成交量（万股，e.g., 38.43）
M：历史滚动窗口期（默认20日）
ε：防零常数（固定为1e-6）

1. 计算步骤（每日执行） 计算历史均值（过去M日，排除当日）：
meanV = 前M日成交量平均值

2. 计算日间变化：
ΔC = conc_t - conc_{t-1}（集中度变化）
ΔP = profit_t - profit_{t-1}（获利比例变化）

3. 计算“有效吸筹力度”（Numerator: Power）与信号过滤：
过滤微小噪音：
if ΔC < 0.05: ΔC = 0
if ΔP < 0.5: ΔP = 0 （获利盘波动通常较大，阈值设为0.5以过滤自然波动）
双引擎核心逻辑（取最大有效值）：
Power = max(ΔC, ΔP * 0.4)
注：系数 0.4 是为了将获利盘变化的量级平滑至与集中度相当的水平，防止数值失真。

4.计算标准化 AEI（核心公式）：
if Power <= 0:
    AEI_t = 0.0  # 无效（无筹码集中 且 无获利盘增加）
else:
    # 分母衡量“资金消耗/努力程度” (Effort)
    # 使用 (vol_t / meanV) 代表当日成交量相对于历史均量的倍数。
    # 逻辑：成交量越低（Effort越小）但Power很大，则AEI越高（效率极高，隐性吸筹）。
    Effort = (vol_t / meanV) + ε
AEI_t = Power / Effort

AEI_smoothed = EMA(AEI_t, span=3)
