# 3. 建立“AI写代码规范”

这个非常重要。

你以后不要说：

---

```
你是一名资深Python工程师。

目标：
我要实现XXX。

我的环境：
Windows 11
Python 3.12
VS Code
Chrome浏览器

限制：
1. 不使用付费API
2. 使用本地Chrome profile
3. 支持断点恢复
4. 输出Excel
5. 有错误日志

请：
1. 先设计方案
2. 再输出代码
3. 解释关键模块
4. 告诉我未来如何维护
```

---

这会明显提高代码质量。

# 4. 学会让AI“维护代码”

这是非程序员最容易忽略的。

不要只：

> 给我写代码


而应该：

> 这是我的旧代码，请先分析架构，再优化。

例如：

```
这是我之前抓Yahoo Finance数据的脚本。

问题：
1. 经常被限制
2. 数据格式混乱
3. 不方便扩展股票

请：
- 分析问题
- 不改变功能
- 重构
- 保留兼容性
```

这才是未来生产力。
