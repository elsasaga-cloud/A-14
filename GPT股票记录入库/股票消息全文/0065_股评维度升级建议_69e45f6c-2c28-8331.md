# 二、逐个给你拆（重点讲清楚“为什么”）

## 1️⃣ 回购记录（Buyback Quality）👉你提到的，非常关键

不是简单“有没有回购”，而是：

### ✔ 要看三点：
- 是否**低估时回购**
- 是否**持续回购**
- 是否**不是靠举债回购**

### ❌ 典型坑：
- 高估时疯狂回购（毁灭股东价值）
- 一边回购一边增发（骗自己）

👉 你可以打分逻辑：

| 情况 | 分数 |
|------|------|
| 持续低估回购 | 5 |
| 偶尔回购 | 3 |
| 高位回购 | 1 |
| 无回购 | 2（中性） |
