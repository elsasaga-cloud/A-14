# 一个完整的资本市场认知框架

## 第一层：产业（Industry）——一切的起点

真正推动资本市场变化的，不是价格，而是产业。

例如：

AI出现；
GPU需求爆发；
云厂商CapEx增加；
光通信升级；
半导体周期上行……

这些属于产业变化。

产业变化最终才会改变企业未来盈利能力。

所以真正的因果关系应该是：

> **产业决定企业，而不是企业决定产业。**

因此我为什么一直强调：

**赛道第一。**

没有产业趋势，再优秀的企业，也可能长期没有资金关注。

所以：

```
产业变化
        ↓
企业未来盈利变化
```

# 第二层：企业（Business）

产业变化以后，真正发生变化的是企业。

例如：

订单增加；
毛利率提高；
竞争力增强；
护城河扩大；
现金流改善。

但是对于普通散户来说：

这一层几乎没有能力比机构研究得更深。

机构拥有：

- 产业调研
- 供应链访谈
- 管理层交流
- 数据服务
- 行业专家

散户没有。

所以：

**我不是否定基本面。**

而是：

> **承认自己的能力边界。**

---

# 第三层：资本配置（Capital Allocation）——整个体系最核心的一层

这是我认为我们讨论最大的收获。

以前我们一直说：

机构锁仓。

后来我越来越觉得：

真正发生变化的是：

> **资本重新配置。**

资本每天都在问一个问题：

> 我的钱放在哪里，未来几年风险收益比最高？

于是：

如果AI最好：

资本进入AI。

如果半导体最好：

资本进入半导体。

如果消费开始占优：

资本又流向消费。

所以：

真正研究的不是：

```
机构有没有卖
```

而是：

```
资本有没有离开。
```

这两个完全不是一回事。

例如：

BlackRock卖了NVDA。

有可能：

```
NVDA

↓

SOXX ETF

↓

QQQ

↓

AI基金
```

资本根本没离开AI。

只是：

持有形式变了。

所以：

真正值得研究的是：

> **资本配置方向。**

# 第四层：资本停留（Holding Time）

这一层其实是你整个体系真正想观察的东西。

以前我们一直说：

平均成本低。

后来我们发现：

成本只是一个结果。

真正重要的是：

> **资本愿意停留多久。**

为什么？

因为：

如果产业越来越好；

企业越来越强；

资本自然愿意一直拿。

于是：

时间越来越长；

成本越来越低。

所以：

其实：

```
Holding Time
        ↓
Holding Cost
```

而不是：

```
Holding Cost
        ↓
Holding Time
```

这是动态思维。

也是静态与动态最大的区别。

你说的：

"锁仓成本低"

其实没有错。

只是：

这是某一个时间点观察到的静态结果。

而：

资本停留时间：

解释了：

为什么它会越来越低。

以前：

if Power <= 0:

Effort = (vol\_t / meanV) + ε
AEI\_t = Power / Effort

## PHASE 1｜资本进入评估 AEI

### Capital Entry Index

目的：判断是否有新资本正在进入

```
Delta_C = concentration_t - concentration_{t-1}
Delta_P = profit_ratio_t - profit_ratio_{t-1}

过滤噪音：
  if Delta_C < 0.05 → Delta_C = 0
  if Delta_P < 0.50 → Delta_P = 0

Power = max(Delta_C, Delta_P × 0.4)
Effort = volume_t / mean_volume_20d + ε

if Power ≤ 0:
    AEI = 0
else:
    AEI = Power / Effort

AEI_smoothed = EMA(AEI, span=3)
```

判断表：

| AEI     | 信号 | 含义     |
| ------- | -- | ------ |
| > 3.0   | S级 | 暴力吸筹   |
| 1.5–3.0 | A级 | 积极吸筹   |
| 0.5–1.5 | B级 | 试探性进入  |
| 0–0.5   | 弱  | 正常波动   |
| 0       | 中性 | 锁仓/钝化期 |
| < 0     | 派发 | 筹码发散   |

趋势判断：

```
5日累计 AEI = sum(AEI_t-4 to AEI_t)

> 4.5 → 真吸筹趋势
2.5–4.5 → 弱真（需观察）
< 2.5 → 假吸筹/中性
```

动态校准（强制执行）：

- AEI = 0 连续 ≥ 3 天，但股价未跌且获利盘未减 → 判定为"主力锁仓"，非无吸筹
- 当日 AEI 创 20 日新高 → 必须标注"超预期爆发性吸筹"

## PHASE 2｜资本停留评估 CPS

### Capital Persistence Score（0–100分）

目的：判断已进入的资本是否在持续停留

这是与 AEI 的本质区别：

- AEI = 有没有新钱进来？
- CPS = 原来的钱还在不在？

```
CPS = 0.40 × Cost_Stability
    + 0.25 × Turnover_Absorption
    + 0.20 × Profit_Retention
    + 0.15 × Price_Structure
```

### 2.1 成本稳定性 Cost\_Stability

衡量：原有资本是否继续存在（20日成本漂移）

```
cost_change = abs(avg_cost_t - avg_cost_{t-20}) / avg_cost_{t-20}
Cost_Stability = clamp(1 - cost_change, 0, 1)
```

| 值       | 含义          |
| ------- | ----------- |
| 0.9–1.0 | 高度锁仓，成本几乎不动 |
| 0.7–0.9 | 稳定，少量换手     |
| < 0.7   | 成本明显迁移，换手较大 |

> 注意：成本稳定 ≠ 一定好。需结合方向判断——成本微升+价格上涨=健康；成本快速上移=资金换手大。

### 2.2 换手吸收 Turnover\_Absorption

衡量：价格上涨是否消耗了越来越少的交易量（越缩量上涨越好）

```
Price_Return = (price_t - price_{t-20}) / price_{t-20}
Volume_Ratio = volume_ma5 / volume_ma20
Turnover_Absorption = Price_Return / Volume_Ratio
→ 标准化至 0–100
```

| 情形      | 分数      |
| ------- | ------- |
| 上涨 + 缩量 | 高（筹码锁死） |
| 上涨 + 放量 | 中（换手健康） |
| 下跌 + 放量 | 低（派发信号） |

### 2.3 获利盘保持 Profit\_Retention

衡量：盈利筹码有没有大量兑现

```
Profit_Change = abs(profit_ratio_t - profit_ratio_{t-20})
Profit_Retention = clamp(1 - Profit_Change / 100, 0, 1)
```

> 关键：不是看获利盘高低，看的是变化幅度。
> 60%→65%→63% = 优秀（没人跑）
> 60%→45%→30% = 预警（盈利盘在撤）

### 2.4 价格结构 Price\_Structure

衡量：价格是否维持在资本成本优势区

```
penetration = (price_t - low_70_t) / (high_70_t - low_70_t) × 100
trend = price_t > avg_cost_t

Price_Structure 评分：
  trend=True  + penetration 20–80 → 高分（黄金攻击区）
  trend=True  + penetration > 80  → 中高（高位锁仓）
  trend=False + penetration > 10  → 中低（水下蓄势）
  trend=False + penetration < 10  → 低（破位风险）
```

CPS 综合判断：

| CPS   | 含义          |
| ----- | ----------- |
| ≥ 80  | 资本深度停留，锁仓明显 |
| 60–80 | 健康持有        |
| 40–60 | 持有一般，需观察    |
| < 40  | 资本不稳定，警惕    |

### 4.1 现价差值法（P评分）

| P值      | 结论       |
| ------- | -------- |
| ≤ -3    | 强空头，不碰   |
| -2 \~ 0 | 弱空/粘合，观望 |
| 1 \~ 2  | 多头初启，观察  |
| ≥ 3     | 稳定多头，可跟  |

### 4.2 State 判定（日K 10根均线）

```python
if P < MA30 < MA60 < MA90:

# State 3/3+：结构性多头
elif P > MA30 > MA60 > MA90:
    State = 3
    if P > MA10 > MA30 > MA50 > MA70 > MA90:
        State = "3+"

# State 2：非完整多头，但结构开始允许
elif P > MA30 and abs(Gap60) < 0.01:
    State = 2
    if P > MA30 and P > MA60:  # 硬前置条件
        MaxGap = max(abs(Gap10..Gap60))
        if MaxGap <= 0.015: SubState = "2B-Compress"
        elif MaxGap <= 0.03: SubState = "2B-EarlyBull"
        else: SubState = "2A"
    else:
        SubState = "2A"

# State 1：弱反弹
```

## PHASE 5｜趋势-偏离双因子 GS模型

斜率解决方向和速度，Gap解决距离和风险

### 5.1 Gap计算（所有10根均线）

```
GapX = (P - MAX) / MAX

需输出：Gap5 / Gap10 / Gap20 / Gap30 / Gap40 / Gap50 / Gap60 / Gap70 / Gap80 / Gap90
```

### 5.2 斜率计算（所有10根均线）

```
SlopeX = (MAx_today - MAx_yesterday) / MAx_yesterday × 100
（%/日，需输出所有10根）
```

### 5.3 GS综合评分

```
TotalScore = StateScore × 0.4 + SlopeScore × 0.3 + GapScore × 0.3
```

StateScore 映射：

| State        | 分数  |
| ------------ | --- |
| 0            | 0   |
| 1            | 20  |
| 2A           | 40  |
| 2B-Compress  | 80  |
| 2B-EarlyBull | 90  |
| 3            | 95  |
| 3+           | 100 |
| X            | 30  |

SlopeScore 逻辑（基于 S10/S20/S30）：

```python
score = 0
if S10 > 0 and S20 > 0 and S30 > 0: score += 40
if S10 > S20 > S30: score += 30          # 加速
if abs(S20 - S30) < 0.1: score += 20    # 中期稳定

SlopeScore = clamp(score, 0, 100)
```

## PHASE 6｜筹码结构判断

### 6.1 穿透率

```
penetration = (P - low_70) / (high_70 - low_70) × 100

< 15：弱势区（容易假突破）
20–60：稳健区（战略性区间）
> 80：过热区（风险）
```

### 6.2 成本溢价

```
cost_premium = (P / avg_cost - 1) × 100

< 0：股价在成本下方 → 明确弱势
0–3：趋势刚启动
3–10：健康上涨
> 10：风险区
```

### 6.3 资本停留时间估算（新增）

这是从"静态成本"升级为"动态承诺"的核心指标

```
estimated_holding_days = 流通市值 / (日均成交额 × 换手集中期)

补充判断：
  avg_cost 过去20日漂移 < 2% → 资本停留时间长（高承诺）
  avg_cost 过去20日漂移 > 10% → 资本换手频繁（低承诺）
```

逻辑：成本几乎不动 = 持有者没有大规模换手 = 资本承诺深

### 6.4 BUY/HOLD/SELL 信号

```python
trend = P > avg_cost
penetration = (P - low_70) / (high_70 - low_70) × 100

if trend and 20 <= penetration <= 80 and volume_ratio >= 1.0:
    signal = "BUY"

elif not trend and (penetration < 10 or cost_premium < -3.0):
```
