# 建议你追加的核心规则

---

## 1）必须加入「多层数据源优先级系统」

你现在只是：

> 一个不行切换另外一个

这还不够。

应该明确：

```text
一级：
API（akshare/yfinance）

二级：
网页 JSON 接口

三级：
真实 Chrome DOM 抓取

四级：
OCR/截图识别（极端情况）
```

原因：

- API 最稳定
- JSON 接口最快最准
- DOM 最容易被网站改版影响
- OCR 是最后保底

否则很多模型会一上来就 Selenium 抓页面，非常蠢。

你应该明确：

> 优先抓接口而不是页面元素。

这是巨大优化。

---

# 2）明确禁止“无等待”的高速爬取

建议加入：

```text
所有抓取必须模拟真人行为：
- 随机停顿
- 页面加载检测
- network idle 检测
- retry
- exponential backoff
```

否则：

- 东方财富容易封
- 腾讯容易限流
- 新浪会403
- YFinance会频繁 challenge

你现在只是说“慢慢来”，但不够工程化。
