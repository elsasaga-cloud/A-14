# 一、为什么美国铝业走势像过山车

原因很简单：  

**铝 = 强周期商品**

公司盈利几乎完全取决于 **铝价**。

过去几年财务表现就是典型例子：

- 2021：大宗商品牛市 → 利润暴涨  
- 2022：利润开始下滑  
- 2023：出现 **大额亏损**  
- 2024：才开始恢复盈利 citeturn0search1

也就是说：

```
铝价上涨 → 赚钱
铝价下跌 → 亏钱
```

几乎没有中间状态。

所以股价自然就是：

```
commodity cycle = stock cycle
```

这也是为什么你看到：

```
大涨 → 大跌 → 大涨 → 大跌
```

---

# 二、为什么铜股不一样

你提到的 **南方铜业**确实是个好对比。

entity["stock","Southern Copper Corporation","NYSE:SCCO"]

铜和铝最大的区别：

### 铜
需求持续结构增长

来源：

- 电网
- AI电力
- 电动车
- 新能源

所以：

```
铜 = structural shortage
```

因此很多铜股 **长期上行**。

---

### 铝

铝的特点：

```
供应容易增加
中国占全球产量 > 50%
```

所以：

```
价格更周期
```

---

# 三、美国铝业其实就是“交易股”

投资逻辑通常是：

```
低价买 → 商品周期来 → 卖
```

不是长期复利股。

很多机构也是这么玩。

在 Reddit 投资社区里就有人总结：

> “snatch it up on the cyclical low then dump it”  
> （周期底部买，涨起来就卖） citeturn0reddit32

其实非常真实。

---

# 四、铝的周期一般多久

大概：

```
3-6年
```

典型节奏：

```
经济复苏
→ 金属需求增加
→ 铝价上涨
→ 新产能出来
→ 价格下跌
```

然后循环。

---

# 五、美国铝业能不能关注？

我觉得 **可以关注，但不要当核心资产**。

原因：

优点：

- 全球老牌铝巨头
- 成本结构不错
- 市值不大（十几到几十亿级）
- 商品周期弹性很大

缺点：

- 分红很一般
- 盈利不稳定
- 很容易变成 **价值陷阱**

其实报告也指出：

**利润和现金流高度波动**，公司在行业低谷甚至会亏损。 citeturn0search1
