# 一、垂直策略（Vertical Spread）
就是 **同方向两个期权，行权价不同**。

最常见结构：

### 看跌垂直（Bear Put Spread）

例子（假设股票 $100）：

买  
PUT 100  

卖  
PUT 90  

结构：

```
买 PUT 100
卖 PUT 90
```

逻辑：

你认为股票 **会跌，但不会暴跌**。

收益结构：

|价格|结果|
|---|---|
100以上 | 全亏 |
100 → 90 | 开始赚钱 |
90以下 | 利润封顶 |

为什么要这样做？

因为：

- 单买PUT **太贵**
- 卖一个低行权价PUT **补贴成本**

所以：

**降低成本 + 限制收益**

这是机构最常用的策略之一。

---

### 看涨垂直（Bull Call Spread）

例子：

买  
CALL 100  

卖  
CALL 110  

结构：

```
买 CALL 100
卖 CALL 110
```

逻辑：

你认为股票 **会涨，但不会暴涨**。

收益结构：

|价格|结果|
|---|---|
100以下 | 全亏 |
100 → 110 | 开始赚钱 |
110以上 | 利润封顶 |

核心思想：

**用卖出的CALL补贴买CALL的成本。**

所以：

单腿CALL是

```
无限收益
高成本
```

垂直策略是

```
有限收益
低成本
```

---

# 二、股票担保（Protective Put）
这个其实是**机构常用的保险策略**。

结构：

```
持有100股股票
买一张PUT
```

比如：

你买了

entity["stock","Tesla Inc.","TSLA stock"]  
100股  
价格 $200

你担心暴跌。

于是：

买

PUT 180

结构：

```
100股 TSLA
+ PUT 180
```

效果：

|股价|结果|
|---|---|
200 → 300 | 正常赚钱 |
200 → 180 | 小亏 |
180以下 | 不再亏 |

因为：

PUT给你**卖出权利**。

所以

```
最大亏损 = 股票成本 - PUT行权价 + PUT成本
```

本质就是：

**给股票买保险。**

很多基金都会这样干。

---

# 三、跨式策略（Straddle）

结构：

```
买 CALL
买 PUT
同一个行权价
```

例子：

股票 $100

买：

CALL 100  
PUT 100  

结构：

```
CALL 100
PUT 100
```

逻辑：

你不知道方向  
但你确定

**要大波动**

例如：

- 财报
- FDA审批
- 战争
- 大事件

只要：

```
大涨 或 大跌
```

都赚钱。

收益结构：

```
       /
_____/  \_____
```

中间亏钱  
两边赚钱。

---

# 四、宽跨式（Strangle）你理解的是对的

结构：

```
CALL 110
PUT 90
```

和跨式区别：

|策略|行权价|
|---|---|
跨式 | 相同 |
宽跨式 | 不同 |

宽跨式：

优点

- 成本更低

缺点

- 必须波动更大才赚钱

# 1️⃣ Covered Call（最经典，巴菲特都用）

结构：

```
买100股股票
卖一张CALL
```

例子：

你持有  
entity["stock","Apple Inc.","AAPL stock"]  
100股  
价格 $200

你卖：

CALL 220  
收到 $3

结果：

|股价|结果|
|---|---|
200以下 | 股票不涨，但赚 $300 |
200 → 220 | 股票涨 + 期权费 |
220以上 | 股票被卖掉 |

核心逻辑：

**拿股票 + 收租**

所以很多美股投资者叫它：

**股票收租策略**

收益来源：

- 股票上涨
- 期权时间价值

缺点：

涨太多你赚不到。

---

# 2️⃣ Cash Secured Put（抄底神器）

结构：

```
卖PUT
准备好现金
```

例子：

entity["stock","Tesla Inc.","TSLA stock"]  
现在 $200

你愿意 $180 买。

于是：

卖  
PUT 180  

收到 $4

结果：

|股价|结果|
|---|---|
200以上 | 白赚 $400 |
180 | 买到股票 |
150 | 被套 |

逻辑：

**拿钱等人把股票卖给你。**

所以很多美股玩家说：

> 与其挂限价单，不如卖PUT。

因为：

**限价单没利息  
PUT有期权费**

---

# 3️⃣ Wheel Strategy（散户最稳定策略）

这个其实是 **策略循环**。

步骤：

```
1 卖PUT
2 被行权买股票
3 卖CALL
4 股票被卖掉
5 再卖PUT
```

循环：

```
卖PUT
↓
买股票
↓
卖CALL
↓
卖掉股票
↓
继续卖PUT
```

很多人专门对：

entity["stock","Ford Motor Company","F stock"]  
entity["stock","Intel Corporation","INTC stock"]  
这种股票这么干。

原因：

**稳定 + 高现金流。**

收益来源：

- PUT权利金
- CALL权利金
- 股票差价

---

# 4️⃣ Vertical Spread（垂直价差）

这个是**降低赌注版本的方向交易**。

例子：

看涨  
买 CALL 100  
卖 CALL 110  

结果：

|股价|结果|
|---|---|
100以下 | 亏 |
100 → 110 | 赚 |
110以上 | 收益封顶 |

逻辑：

```
单腿CALL = 高风险
价差CALL = 限制风险
```

机构很喜欢这种。

因为：

**资金效率高。**

---

# 5️⃣ Iron Condor（机构最爱）

这个其实是**卖波动率**。

结构：

```
卖CALL
买CALL（保护）

卖PUT
买PUT（保护）
```

形成一个区间：

```
      CALL
-------|---------
       |
       | 赚钱区
       |
-------|---------
      PUT
```

逻辑：

只要股价：

**不大涨 不大跌**

就赚钱。

适合：

- 大盘
- 横盘股票

很多交易员对：

entity["stock","SPDR S&P 500 ETF Trust","SPY ETF"]  
天天这么干。

因为：

**市场70%时间都在震荡。**

---

# 总结一下（期权赚钱核心）

5大结构：

|策略|赚钱逻辑|
|---|---|
Covered Call | 股票 + 收租 |
Cash Secured Put | 抄底收租 |
Wheel | 收租循环 |
Vertical Spread | 方向交易 |
Iron Condor | 卖波动率 |

你会发现一个很重要的事：

真正长期赚钱的策略  
**大部分都在卖期权。**

因为：

```
期权买方 = 赌徒
期权卖方 = 赌场
```

时间衰减永远存在。

> 老手卖期权。
